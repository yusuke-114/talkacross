# TalkAcross

面向 iPhone 的中日语音翻译 App。按住麦克风说话，松手后显示原文和译文，并自动朗读译文。

## 功能

- 普通话和日语双向互译，支持语音和文字输入。
- 支持上海话翻成日语。下载转换包后，先在设备上将上海话转成普通话，再翻成日语。
- 可以重听译文，无需注册，也不会保存翻译历史。
- 界面支持简体中文和日语。

## 使用方法

需要运行 iOS 26.0 或更新版本的 iPhone。

1. 首次使用时，在 App 的**设置**中下载所需的语音识别和翻译资源。
2. 在首页选择翻译方向。中文作为输入语言时，可以选择普通话或上海话。
3. 按住麦克风说话，松手后查看并收听译文。也可以点原文区的键盘图标输入文字。

普通话和日语的识别可使用 Apple 原生识别或 WhisperKit。上海话需要单独下载约 310 MB 的转换包，上海话语音识别可能需要联网。
